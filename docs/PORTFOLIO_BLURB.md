# Portfolio Blurb

## Short Version

Built a production-style Customer Churn Prediction system using Python, scikit-learn, XGBoost, MLflow, FastAPI, and SQLite. The project covers the full ML lifecycle: ingestion, validation, feature engineering, model training, experiment tracking, model registry, API inference, online serving metrics, drift detection, and retraining triggers.

## Medium Version

This project demonstrates how I structure machine learning systems beyond notebook experimentation. I used the BankChurners dataset to build a modular churn prediction platform with Pandera-based schema validation, sklearn preprocessing pipelines, model comparison across Logistic Regression, Random Forest, and XGBoost, MLflow experiment tracking and registry, FastAPI inference, a browser-based prediction UI, persistent online serving metrics, and drift monitoring with retraining hooks.
